▦QR Studio

สร้าง QR Code จากข้อความ ลิงก์ หรือไฟล์ที่โฮสต์ไว้แล้ว — ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องมีเซิร์ฟเวอร์

🔒 ประมวลผลในเครื่องคุณทั้งหมด  •  ไม่เก็บข้อมูลของคุณไว้ที่ไหน

สร้าง QR จากข้อความหรือลิงก์

รองรับ URL เว็บไซต์, ข้อความทั่วไป, เบอร์โทร, อีเมล ฯลฯ

สร้าง QR จากลิงก์ไฟล์ (PDF / รูปภาพ / เอกสาร)

📌 เว็บนี้เป็นแบบ Static (โฮสต์บน GitHub Pages) จึงไม่มีเซิร์ฟเวอร์เก็บไฟล์ ให้คุณอัปโหลดไฟล์ไปยังบริการอื่นก่อน เช่น Google Drive, Dropbox, GitHub เอง หรือเว็บฝากไฟล์ใดๆ แล้วคัดลอก "ลิงก์แชร์" มาวางด้านล่างเพื่อสร้าง QR Code ที่ชี้ไปยังไฟล์นั้น

QR Code ของคุณพร้อมแล้ว 🎉
